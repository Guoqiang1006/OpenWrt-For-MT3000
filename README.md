# GL-MT3000 中文 OpenWrt 定制固件

适用于 **GL.iNet Beryl AX / GL-MT3000** 的纯 OpenWrt 定制系统，提供中文网页管理、首次配置向导和预装插件。

> 当前为 **v1.0.0 预发布版**：完整镜像已通过构建及文件校验；部分功能有单台设备及在线更新验证记录，但这份最新完整镜像尚未再次整包刷入。手机 USB、真实酒店认证、公网 IPv6、WPA3 等场景仍需对应环境实测。

**安装顺序：确认型号 → 下载 → 校验 → 接线与备份 → 刷写 → 首次登录 → 配置向导 → 检查上网 → 设置 OpenClash → 按需启用其他功能。**

以下以“从原厂 GL.iNet 系统全新安装”为主线。已经使用本定制固件的用户，在第 5 步按“同系列升级”处理。

## 第 1 步：确认型号，准备工具

1. 查看路由器底部标签，确认型号为 **GL-MT3000 / Beryl AX**。其他 GL.iNet 型号不能使用此安装包；国行或海外销售标签不能代替型号和硬件版本核对。
2. 准备一台电脑、一根能接到路由器 **LAN 口**的网线，以及稳定电源。电脑没有网口时，准备 USB 转以太网适配器。
3. 记下现有宽带拨号账号、无线设置，以及自己需要保留的配置；稍后另做系统备份。
4. 接受系统迁移后的变化：这是第三方纯 OpenWrt，**不保留原厂 GL.iNet App、GoodCloud 和原厂管理界面**。之后使用电脑或手机浏览器管理。

**全新安装后 Wi-Fi 默认关闭，必须先通过 LAN 网线完成首次配置。路由器 USB-C 是供电口，不能作为电脑管理网口。**

## 第 2 步：下载固件和说明书

打开 **[v1.0.0 发布页面](https://github.com/Guoqiang1006/OpenWrt-For-MT3000/releases/tag/v1.0.0)**，在 **Assets** 中下载附件。

推荐下载 [固件与说明书整包 ZIP](https://github.com/Guoqiang1006/OpenWrt-For-MT3000/releases/download/v1.0.0/MT3000-Firmware-and-Manual-v1.0.0.zip)，然后解压到电脑本地文件夹。文件用途如下：

| 文件 | 用途 |
| --- | --- |
| `openwrt-25.12.6-zh-openclash-mediatek-filogic-glinet_gl-mt3000-squashfs-sysupgrade.bin` | **刷写时上传的固件文件** |
| `MT3000-User-Manual-v1.0.pdf` | 12 页产品功能手册 |
| `MT3000-User-Manual-v1.0.docx` | 可编辑 Word 手册 |
| `SHA256SUMS` | 文件完整性校验值 |
| `packages.manifest` | 预装组件清单 |
| `RELEASE-NOTES.md` | 版本说明及尚待实测的项目 |

**刷写页面只上传上表中的 `.bin` 文件，不上传 ZIP、PDF、Word，或 GitHub 自动生成的 Source code 压缩包。**

先完成下载再进行后续操作。固件放在 Releases 附件中，仓库文件列表不保存固件二进制。

## 第 3 步：核对下载文件

在电脑上打开终端，进入整包解压后的文件夹，按操作系统选择一种方式。

**macOS：**

```sh
shasum -a 256 -c SHA256SUMS
```

**Linux：**

```sh
sha256sum -c SHA256SUMS
```

整包中的四个校验文件都应显示 `OK`。若只下载了单独固件，可以用下列方式仅校验该文件。

**Windows，在固件所在文件夹打开 PowerShell：**

```powershell
Get-FileHash -Algorithm SHA256 .\openwrt-25.12.6-zh-openclash-mediatek-filogic-glinet_gl-mt3000-squashfs-sysupgrade.bin
```

本版本固件的 SHA256 应为下列值，大小写不影响比较：

```text
7bded5ff1548ee6b3d76bd2c56b582c2073bbf050073d2691a8413ff7b5b321b
```

文件大小为 **51,261,782 字节**。校验不一致时重新下载，不继续刷写。校验一致只说明文件完整，仍需确认型号匹配。

## 第 4 步：接好网线，登录并备份旧系统

1. 路由器 USB-C 接电源，电脑通过网线连接 **LAN 口**，不要误接 WAN 口。
2. 电脑以太网设置为“自动获取 IP 地址 / DHCP”。为避免访问错设备，刷写期间暂时断开电脑连接其他路由器的 Wi-Fi。
3. 在浏览器打开 **http://192.168.8.1**，用现有管理员密码登录。若你修改过管理地址，使用实际地址。
4. 原厂系统进入“**系统 → 高级设置 → LuCI**”，按页面提示进入 LuCI，再打开“**系统 → 备份 / 升级**”，生成并下载配置备份。如果原厂尚未安装 LuCI，按高级设置页面提示先安装。已经使用 OpenWrt 的用户可直接进入该备份页面。
5. 确认备份已保存到电脑，再进行下一步。备份可能包含密码和密钥，仅自己保管，不上传公开仓库。

原厂配置备份用于匹配的原厂系统恢复，**不能直接恢复到本纯 OpenWrt 系统**。原厂界面入口可参考 [GL.iNet 官方升级与备份说明](https://docs.gl-inet.com/router/en/4/tutorials/how_to_upgrade_downgrade_router/)。

## 第 5 步：上传固件，选择正确的保留设置方式

根据当前系统，选择下面一种入口操作，不需要两个入口都刷。

### A. 当前是原厂 GL.iNet 系统

1. 回到原厂管理页面，进入“**系统 → 升级 → 本地升级**”（`SYSTEM → Upgrade → Local Upgrade`）。
2. 上传第 2 步解压得到的 **`…glinet_gl-mt3000-squashfs-sysupgrade.bin`** 文件，等待页面检查。
3. **关闭“保留设置 / Keep Settings”。** 从原厂迁移到纯 OpenWrt 不沿用原厂配置。
4. 核对文件和设置，点击“安装 / Install”，进入刷写。

MT3000 可通过原厂网页上传 sysupgrade 镜像，迁移时不保留配置，参见 [OpenWrt 的 MT3000 安装说明](https://openwrt.org/toh/gl.inet/gl-mt3000#installation)。

### B. 当前已经是 OpenWrt / 本定制固件

1. 进入“**系统 → 备份 / 升级**”，选择“刷写新的固件 / Flash image”。
2. 上传同一个 `.bin` 文件，等待检查。
3. 根据下表决定是否保留设置，再确认继续。

| 当前情况 | 保留设置方式 |
| --- | --- |
| 从原厂 GL.iNet 系统迁移，包括使用其 LuCI 入口刷写 | **取消保留设置** |
| 从其他来源的 OpenWrt 固件迁移到本固件 | 配置兼容性未经确认时取消保留，之后手动重新配置 |
| 已使用兼容的本定制版本，进行同系列升级 | 先备份、阅读版本说明；通常可以保留兼容设置 |
| 跨大版本或版本说明要求重新配置 | 按对应说明处理，不自行套用保留设置 |

如果页面拒绝镜像、提示型号不匹配、校验失败，或要求“强制刷写”，**停止并重新核对，不勾选强制选项**。不要刷入其他型号文件或改写 bootloader、Factory 分区。

## 第 6 步：等待重启，重新进入管理页

1. 刷写开始后，保持电源和 LAN 网线连接，等待写入及重启完成；期间不要拔电或按复位键。
2. 新系统启动后，浏览器重新打开 **http://192.168.8.1**。
3. 如暂时打不开，先确认电脑仍连接 LAN、以太网为 DHCP；可断开再接回电脑网线，让电脑重新获取地址，再刷新页面。
4. 登录用户名为 **`root`**。全新安装没有预设管理员密码，按页面提示进入并在下一步立即设置；保留设置升级则使用原有密码和原有 LAN 管理地址。

此时看到纯 OpenWrt 中文页面是正常的。**找不到原厂 Wi-Fi 也正常：全新安装需要先通过网线自行设置和启用无线。**

## 第 7 步：按向导完成首次配置

进入“**系统 → 首次配置向导**”，依次操作：

1. **管理员密码**：填写两遍一致的新密码，长度 10–128 个字符。已有密码且希望保留时，两项留空。管理员密码与 Wi-Fi 密码是两回事。
2. **地区和时区**：按实际所在地选择。例如在中国大陆使用时选择“中国大陆（CN）”与北京时间 `Asia/Shanghai`。全新镜像预设 AU / Australia/Sydney，应自行核对修改。
3. **无线网络**：勾选设置主无线，填写 Wi-Fi 名称和密码。Wi-Fi 密码为 8–63 字节；向导为两个频段设置同名同密码的 WPA2 主网络。
4. **上网方式**：连接上级路由器时选择“自动获取地址 / DHCP”；运营商需要拨号时选择 PPPoE 并填账号密码；只有上游明确要求固定地址时才选择静态 IPv4。使用手机 USB 或 Travelmate 时，先保留 WAN 设置，再按第 8 步配置对应上游。
5. **IPv6**：不需要 IPv6 时可选“局域网仅 IPv4”；保留现状、原生 IPv6 和 OpenClash IPv6 的区别见手册第 7 页。启用代理 IPv6 还需要上游与规则配合。
6. **AdGuard 故障策略**：暂不使用 AdGuard 时保持默认即可；此处不会自动启用过滤。可选串联的设置见手册第 6 页。
7. 核对摘要，点击应用，按页面提示重新连接并确认网络设置。若管理员密码已修改，用新密码重新登录。

打开向导本身不会改配置。**密码修改立即生效，不随网络设置回退**。高级用户已有自定义网络时，按实际情况保留配置，不要为了完成向导覆盖原有设置。

## 第 8 步：接入上游，先确认普通上网正常

选择你实际使用的一种上网方式：

| 方式 | 接线与操作 | 检查位置 |
| --- | --- | --- |
| 上级路由器供网，例如华硕 | 上级路由器 **LAN → MT3000 WAN**；MT3000 的 WAN 使用 DHCP | “网络 → 接口”中 WAN 获取地址 |
| 运营商宽带拨号 | 按宽带接入要求连接 WAN，在向导或接口页填写 PPPoE 账号密码 | WAN 拨号成功并取得地址 |
| Android 手机 USB 共享 | 数据线接 MT3000 **USB-A**，手机开启“USB 网络共享”；USB-C 继续给路由器供电 | 接口页查看 `usbwan` |
| iPhone USB 共享 | 数据线接 USB-A，开启个人热点，解锁并确认“信任”；USB-C 继续供电 | 接口页查看 `iphonewan` |
| 酒店或外部 Wi-Fi | “服务 → Travelmate”，按首次向导创建上游接口、添加无线站点并启用；需要时完成酒店网页认证 | Travelmate 与接口页 |

手机 USB 驱动及接口逻辑已集成，但尚无本固件的实测机型白名单；部分机型可能需要额外处理。有线 WAN 默认优先，这个版本没有完整的互联网故障自动切换服务。

如果上级路由器也使用 `192.168.8.0/24`，先把 MT3000 的 LAN 改为不冲突的网段并记下新管理地址，再接入该上游。

完成接入后：

1. 打开“**状态 → 路由器首页**”，检查上网地址和系统时间；需要时点击“检查网络”测试 DNS 和 HTTPS。
2. 让电脑或手机连接刚设置的 MT3000 Wi-Fi，或继续连接 LAN，先测试普通网站。
3. 普通上网正常后，再启用下一步的 OpenClash。核心运行、接口有地址、单个测试通过，都不能单独证明所有设备及网站可用。

## 第 9 步：添加自己的配置，再启用 OpenClash

如果不需要 OpenClash，可以跳过本步，保持关闭。

1. 进入“**服务 → OpenClash**”。固件已预装插件与内核，无需再次下载安装。
2. 在订阅或配置管理中添加自己的有效配置，完成更新并选择使用。固件**不提供订阅、节点或线路**，不要公开自己的订阅链接。
3. 选择“**规则模式 / Rule**”，检查策略组：需要代理的策略组选择可用节点，国内直连组保持 `DIRECT`。
4. 按配置需要检查“绕过中国大陆 IP”等设置。国内网站是否直连仍由实际规则、DNS 和流量命中情况决定；不要用全局模式代替国内外分流。
5. 将路由器侧面开关置于首页显示的“**开启位置**”，检查 OpenClash 内核状态和日志。若网页临时开启但实体开关仍关闭，重启或下一次拨动时可能再次关闭内核。
6. 用连接 MT3000 的终端分别测试国内网站与需要代理的服务；路径不符合预期时，在 OpenClash 连接记录中查看命中的规则与策略组。

## 第 10 步：按需启用其他功能，完成检查

- **AdGuard Home**：可选，默认关闭。先完成其账户与监听端口设置，再按 PDF 第 6 页接入串联；不要只为消除“未运行”提示而直接启用。
- **无线地区切换**：“网络 → 无线地区切换”，可统一应用到所有无线频段。按实际所在地设置，操作后检查终端能否重新连接。
- **WireGuard / OpenVPN**：按自己取得的地址、密钥、证书和路由要求配置；完整步骤与边界见手册第 9 页。
- **启动项**：保留默认状态，按需启用；无需把所有“已禁用”服务都打开。

最后确认：管理页可登录、Wi-Fi 能连接、普通网站可打开、系统时间合理；如果使用 OpenClash，再确认策略和实体开关一致。保存一份当前纯 OpenWrt 的配置备份，之后升级前另做新备份。

到这里完成首次安装。日常功能和故障排查请查看 [PDF 产品功能手册](MT3000-User-Manual-v1.0.pdf) 或 [Word 可编辑手册](MT3000-User-Manual-v1.0.docx)。

## 安装中遇到问题

| 现象 | 先处理什么 |
| --- | --- |
| 刷完找不到 Wi-Fi | 用 LAN 网线登录，完成第 7 步并启用无线 |
| 打不开管理地址 | 检查是否接 LAN、是否自动获取地址；保留设置升级时使用原地址 |
| 镜像被拒绝或提示不匹配 | 停止刷写，重新核对型号、文件与 SHA256；不强制刷写 |
| 能进管理页但不能上网 | 先检查第 8 步的 WAN / 手机 / Travelmate 接入，再检查 DNS |
| OpenClash 已启用但不能连接 | 检查所选配置、节点、时间、DNS、日志和侧面开关 |
| 无法正常启动 | 按下述官方 U-Boot 恢复说明处理 |

需要恢复时参照 [GL.iNet 官方 U-Boot 恢复说明](https://docs.gl-inet.com/router/en/4/faq/debrick/)，使用厂商为 MT3000 指定的恢复文件。普通 sysupgrade、厂商升级包和 U-Boot 恢复文件不能混用。恢复出厂设置只会清除本系统配置，不会自动恢复原厂 GL.iNet 固件。
